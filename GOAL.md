*Набор инструментария, который помогает ИИ Агенту Claude Code быть суппер эффективным в этой работе*:

- REA — Reverse Engineer Anything
Инструментарий для реверс-инжиниринга с помощью AI-агентов. Через MCP агент может исследовать приложения, нативные бинарники, структуру программ, поведение во время выполнения, находить связи и собирать доказательства того, как всё работает.
Для Krinik: исследование оригинального Silent Storm, восстановление непонятных алгоритмов, анализ бинарников и поведения старых компонентов. 
GitHub+1


- Superpowers
Система навыков и методология разработки для AI-агентов. Помогает организовывать работу: исследование требований, проектирование, планы реализации, TDD, параллельная работа субагентов, code review и систематическая отладка.
Для Krinik: заставить агента не просто писать код, а работать по инженерному процессу: сначала разобраться, затем спланировать, реализовать, проверить и проанализировать результат. 
GitHub+1


- Catch2
Современный C++-фреймворк для автоматических тестов: unit-тестирование, TDD, BDD и простые бенчмарки.
Для Krinik: проверять отдельные подсистемы оригинального движка: математические функции, баллистику, расчёты повреждений, игровые правила, физические взаимодействия. 
GitHub+1


- LLVM Project
Большой набор инструментов для C/C++-разработки. Особенно интересны:
- Clang Static Analyzer — статический анализ кода и поиск потенциальных ошибок.
- clang-tidy — обнаружение типичных ошибок программирования, неправильного использования интерфейсов и проблемных конструкций.
- AddressSanitizer / UndefinedBehaviorSanitizer — обнаружение ошибок памяти и неопределённого поведения.
- LibFuzzer — автоматический поиск ошибок путём подачи множества необычных входных данных.
Для Krinik: проверка старого C++-кода, поиск проблем с памятью, некорректных операций и трудноуловимых ошибок. 
Clang+2


- KUIPS — Krinik User Interface Prototyping System
Локальная Figma-подобная система, в которой AI-агенты проектируют интерфейсы приложения: размещают экраны на общей схеме, показывают переходы между ними, состояния и связи. Есть CLI, API и MCP, автоматическое снятие скриншотов через Playwright.
Для Krinik: проектирование интерфейса игры, меню, инвентаря, экранов персонажа, настроек и карт игровых состояний.
