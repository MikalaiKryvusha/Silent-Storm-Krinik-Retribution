## Видение (одной строкой)

Классическая тактика в современном исполнении, которая запускается по ссылке в браузере на любом устройстве — ПК, Steam Deck, Android, MacBook — с современным рендером на WebGPU и удобствами нашего времени.

## Руководящие принципы

- **Браузер — главная платформа.** Игра открывается как сайт, без установки; WebGPU в первую очередь, с честным сообщением, если его нет.
- **Ядро не знает платформы.** Игровая логика на C++ не зависит ни от браузера, ни от графического API (`AGENT_GUIDE.md` → RULE).
- **Любое устройство — первым классом:** любые разрешения и соотношения сторон, мышь, тач и геймпад — с первой же сборки, а не «потом».
- **Сначала работает, потом красиво** (`PHILOSOPHY.md` → Парето): вертикальный срез раньше полировки.
- **Каждая функция приходит со своей проверкой:** Catch2 для ядра, Playwright для браузера, санитайзеры для памяти.

## Путь от здесь до цели — фазы

### Фаза 0 — Фундамент
- **Цель фазы:** методология, инструменты и витрина на месте; любая сессия продуктивна с пустого контекста.
- **Шаги:** развернуть KAIF · найти и подключить инструменты (Emscripten + EmdawnWebGPU, LLVM, Catch2, Superpowers, KUIPS, REA) · `npm run doctor` · README репозитория.
- **Статус:** 🔧 KAIF и инструменты готовы (`npm run doctor` — 13/13 OK, 2026-11-21); README — в работе.

### Фаза 1 — Браузерная платформа (MVP)
- **Цель фазы:** C++ собирается в WASM, рисует через WebGPU и откликается на ввод на ПК и телефоне.
- **Шаги:** CMake-сборка web/native · оболочка HTML/JS (canvas, devicePixelRatio, resize) · единый ввод мышь/тач/колесо/щипок · проверка WebGPU с понятным сообщением · первый Playwright-прогон со снимком.
- **Статус:** 🔧 начата и припаркована (`STATUS.md` → PARKED).

### Фаза 2 — Тактическое ядро прототипа
- **Цель фазы:** пошаговый бой отрядов работает в браузере на временной графике.
- **Шаги:** сетка карты · бойцы и очки действий · поиск пути · линия огня · смена ходов · модульные тесты Catch2 · сборки с ASan/UBSan.
- **Статус:** 🔲

### Фаза 3 — Удобства нашего времени (QoL)
- **Цель фазы:** игра удобна на любом экране и устройстве.
- **Шаги:** настройки графики · локализации · сохранения в браузере (IndexedDB) · офлайн-запуск (PWA) · геймпад · адаптивный интерфейс, спроектированный в KUIPS.
- **Статус:** 🔲

### Фаза 4 — Игра: мир, герои, миссии

- **Шаги:** концепция игры — **решение владельца** (интервью) · миссии · арт и звук · баланс.
- **Статус:** 🔲 ждёт решения владельца
